# BMSCE_PORTAL
An interactive, modern, and responsive academic portal for *BMS College of Engineering, built with **HTML5, Tailwind CSS, and JavaScript*.
## 🚀 Overview
This project is a multi-page web application designed to provide a seamless experience for students, faculty, and recruiters. It features a custom-branded navigation system, dynamic "Mega Menus," and dedicated sections for placements and research.

## ✨ Key Features
* *Modern UI/UX:* Built using Tailwind CSS for a sleek, utility-first design.
* *Multi-Page Architecture:* Includes index, about, academics, placements, research, and campus-life.
* *Interactive Navigation:* A smart sticky header that transitions from transparent to solid white on scroll.
* *Placement Roadmap:* A visual step-by-step guide for student career success.
* *Responsive Design:* Fully optimized for mobile, tablet, and desktop viewing.
* *Lucide Icon Integration:* Clean, vector-based iconography throughout the portal.

## 🛠️ Tech Stack
* *Frontend:* HTML5, Tailwind CSS
* *Scripting:* JavaScript (ES6+)
* *Icons:* [Lucide-Dev](https://lucide.dev/)
* *Fonts:* Inter (via Google Fonts)
