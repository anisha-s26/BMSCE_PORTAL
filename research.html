Featured Research Project

Autonomous Drone Navigation System

This project focuses on developing SLAM-based (Simultaneous Localization and Mapping) algorithms for drones to navigate GPS-denied indoor environments using LiDAR and Computer Vision.

Status Ongoing
Funding ₹12.5 Lakhs

Project Impact

  • Reduced collision rates by 40% in complex industrial warehouses.

  • Implemented real-time obstacle avoidance using Edge AI processing.

  • Published in IEEE International Conference on Robotics and Automation.
